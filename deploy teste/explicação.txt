DOCUMENTAÇÃO COMPLETA DO PROJETO CATÁLOGO DE CARTAS
===================================================

Data de Criação: 29 de maio de 2026
Versão Final: 2.0

RESUMO GERAL
============
Este projeto é um catálogo interativo de cartas de colecionáveis com funcionalidades avançadas de filtro e paginação.
O catálogo contém 139 cartas da coleção "GD01 - Newtype Rising" com imagens, descrições e informações de cores.


HISTÓRICO DE DESENVOLVIMENTO
=============================

ETAPA 1: CRIAÇÃO INICIAL DO PROJETO
-----------------------------------
Foram criados os arquivos base do projeto:
- index.html: Estrutura HTML com modal para visualização detalhada
- style.css: Estilos visuais básicos
- script.js: Lógica de carregamento e exibição de cartas
- cartas.json: Banco de dados com informações das cartas (inicialmente com 2 cartas de teste)

FUNCIONALIDADES INICIAIS:
✓ Grid de 9 cartas por página (3 colunas x 3 linhas)
✓ Modal suspenso ao clicar em uma carta
✓ Exibição de imagem maior e descrição no modal
✓ Botões de navegação (Anterior/Próxima)
✓ Botão de fechar modal (X)
✓ Efeito hover nas cartas (zoom ao passar o mouse)

ARQUIVOS CRIADOS:

ETAPA 2: ATUALIZAÇÃO DO BANCO DE DADOS
---------------------------------------
PROBLEMA: O arquivo cartas.json tinha apenas 2 cartas de teste.
SOLUÇÃO: Script PowerShell foi executado para:
- Escanear a pasta "imagens/GD01 - Newtype Rising/" e identificar todas as 139 imagens
- Gerar automaticamente um novo cartas.json com todas as 139 cartas
- Vincular cada imagem à sua descrição correspondente em "descrição/GD01 - Newtype Rising/"

TAMBÉM FOI CORRIGIDO:
- Caminho das pastas: "descricoes/" → "descrição/" (correção da acentuação)

RESULTADO FINAL:
✓ 139 cartas agora estão cadastradas e funcionando
✓ 15 páginas completas de 9 cartas + 1 página com 4 cartas
✓ Todas as imagens e descrições vinculadas corretamente


ETAPA 3: ADIÇÃO DA BARRA SUPERIOR COM SELETOR DE QUANTIDADE
-----------------------------------------------------------
NOVA FUNCIONALIDADE: Controle dinâmico de cartas por página

HTML (index.html):
- Criada div "barra-superior" com título e seletores
- Adicionado select com opções: 9, 12 ou 24 cartas por página
- O seletor dispara função mudarCartasPorPagina()

CSS (style.css):
- Estilizada barra superior com fundo escuro (#222)
- Borda inferior em destaque (#444)
- Flexbox para layout responsivo
- Estilos para o select com hover effect

JAVASCRIPT (script.js):
- Variável cartasPorPagina agora é LET (não const) para ser modificável
- Função mudarCartasPorPagina(): Captura valor do select e atualiza a quantidade
- Função atualizarGridColunas(): Ajusta dinamicamente o grid:
  * 9 cartas = 3 colunas (padrão)
  * 12 cartas = 4 colunas
  * 24 cartas = 6 colunas
- Resetar para página 1 ao mudar a quantidade

RESULTADO FINAL:
✓ Barra superior com dois seletores funcionando
✓ Grid se adapta automaticamente ao número de cartas selecionadas
✓ Paginação recalculada quando muda a quantidade


ETAPA 4: IMPLEMENTAÇÃO DO FILTRO DE CORES
------------------------------------------
NOVA FUNCIONALIDADE: Filtro por cor das cartas (Blue, Green, Red, White, Purple)

DADOS EXTRAÍDOS: Cada descrição de carta contém "COLOR [cor]" que é parseado

HTML (index.html):
- Adicionado novo select para escolher cor
- Opções: Todas, Blue, Green, Red, White, Purple
- Seletor dispara função mudarCor()
- Ambos seletores agora dentro de div "seletores"

CSS (style.css):
- Div "seletores" com flexbox para lado a lado
- Mantém a responsividade da barra

JAVASCRIPT (script.js):
NOVAS VARIÁVEIS:
- cartasOriginais: Cópia de todas as cartas (sem filtro)
- cartasFiltradas: Array com apenas cartas da cor selecionada
- corSelecionada: String com cor atual selecionada

NOVAS FUNÇÕES:
- carregarCores(): Executa quando carrega as cartas
  * Lê cada arquivo de descrição
  * Usa regex para extrair "COLOR [cor]"
  * Armazena a cor em propriedade "cor" de cada carta
  
- mudarCor(): Chamada quando select de cor muda
  * Se seleção é "Todas": mostra cartasOriginais
  * Se seleção é uma cor específica: filtra cartasFiltradas
  * Volta para página 1 ao mudar filtro
  * Chama mostrarPagina() para atualizar exibição

ATUALIZAÇÕES EXISTENTES:
- mostrarPagina(): Agora usa cartasFiltradas em vez de cartas
- proximaPagina(): Verifica limite com cartasFiltradas
- Exibição de página agora mostra "Página X de Y" total de páginas

RESULTADO FINAL:
✓ Filtro de cores totalmente funcional
✓ 139 cartas categorizadas por cor ao carregar
✓ Combinação de filtros: cor + quantidade de cartas por página
✓ Paginação se adapta ao filtro selecionado
✓ Performance otimizada com carga assíncrona de cores

DADOS DE CADA CARTA
===================

Cada entrada em cartas.json contém:
{
  "nome": "GD01-001",
  "imagem": "imagens/GD01 - Newtype Rising/GD01-001.webp",
  "descricao": "descrição/GD01 - Newtype Rising/GD01-001.txt",
  "cor": "Blue" (adicionado dinamicamente ao carregar)
}

Cada descrição (arquivo .txt) contém informações como:
- Nome da carta
- Nível e custo
- COR (extraída para filtro)
- Tipo (UNIT, SPELL, etc)
- Raridade (LR, R, etc)
- Habilidades
- Atributos (AP, HP)
- Origem


COMO USAR O CATÁLOGO
====================

1. NAVEGAR ENTRE CARTAS:
   - Use os botões "Anterior" e "Próxima" na barra inferior
   - Vê quantas páginas existem (Página X de Y)

2. VER DETALHES DE UMA CARTA:
   - Clique na imagem da carta
   - Uma janela suspensa abre com a imagem grande e descrição
   - Clique no X ou fora da janela para fechar

3. FILTRAR POR COR:
   - Selecione a cor desejada no dropdown "Cor"
   - Apenas cartas dessa cor serão exibidas
   - A paginação se adapta automaticamente
   - Selecione "Todas" para resetar o filtro

4. MUDAR QUANTIDADE POR PÁGINA:
   - Selecione 9, 12 ou 24 no dropdown "Cartas por página"
   - O grid se reorganiza automaticamente
   - Retorna para página 1 ao mudar

TROUBLESHOOTING
===============

PROBLEMA: Modal não abre ao clicar em carta
SOLUÇÃO: Verifique se o arquivo de descrição existe no caminho correto

PROBLEMA: Filtro de cor não funciona
SOLUÇÃO: Certifique-se de que "COLOR [cor]" está escrito corretamente nos arquivos .txt

PROBLEMA: Grid não mostra 24 colunas corretamente
SOLUÇÃO: É esperado; ao invés de 24 colunas, usa 6 colunas com mais linhas para melhor visualização

PROBLEMA: Páginas anteriores/próximas desabilitadas incorretamente
SOLUÇÃO: Verifique se cartasFiltradas está atualizado após filtrar

COMO ADICIONAR NOVAS CARTAS
============================

1. Copie a imagem da carta para: imagens/GD01 - Newtype Rising/
   Nomear como: GD01-XXX.webp

2. Crie arquivo de descrição em: descrição/GD01 - Newtype Rising/
   Nomear como: GD01-XXX.txt
   Incluir "COLOR [Blue|Green|Red|White|Purple]" no conteúdo

3. Adicione entrada em cartas.json:
{
  "nome": "GD01-XXX",
  "imagem": "imagens/GD01 - Newtype Rising/GD01-XXX.webp",
  "descricao": "descrição/GD01 - Newtype Rising/GD01-XXX.txt"
}

4. Recarregue a página - a nova carta aparecerá automaticamente

CATÁLOGOS POR JOGO
==================

A página inicial agora permite escolher um jogo antes de abrir uma edição. A seleção
"Jogos" no menu também permite trocar de jogo sem misturar as quantidades salvas.

O arquivo catalogos/jogos.json registra os jogos, caminhos dos catálogos e edições.
O catálogo existente do Gundam continua em cartas.json. O Cyberpunk TCG tem uma
estrutura inicial em catalogos/cyberpunk/:
- cartas.json: versões das cartas;
- edicoes.json: códigos, nomes e imagens opcionais das edições;
- imagens/ e descrição/: arquivos de imagem e descrição.

O formato dos dados e exemplos para incluir as edições e cartas estão em
catalogos/cyberpunk/README.txt. As quantidades continuam sincronizadas na mesma conta,
mas cada carta usa seu caminho de imagem para manter os jogos separados.
